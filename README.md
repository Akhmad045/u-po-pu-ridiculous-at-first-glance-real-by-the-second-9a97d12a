# Ridiculous at First Glance, Real by the Second

An entry for the [make.fun bounty](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a) of the same name. Referral code: `4g7knchf`.

## The pitch

`main.py` writes one sentence, no more than 200 characters, pitching a
startup that sounds like a joke until the money in it clicks: renting a
single bed to two strangers who work opposite shifts, so each pays half
the rent while the landlord earns twice from one mattress.

## How it works

Run it with Python 3 (standard library only, no network):

```sh
python3 main.py
```

It validates the sentence first — 1 to 200 characters, one line, no
leading or trailing whitespace, no control characters — then writes it to
`/output/entry.txt` as UTF-8 bytes and reads the file back to confirm the
bytes match exactly what was written.
